# Advocacy Plan
{bdg-link-primary-line}`Advocacy and communications <index#advocacy-and-communications>`

An advocacy plan sets out the resource requirements and steps that will be followed to encourage organisations to adopt a standard, as well as key arguments. It should be updated regularly as the standard matures and as the standard starts to have an impact.
